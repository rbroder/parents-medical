# דשבורד רפואי

אתר סטטי לקריאה בלבד. המידע מוצפן ב-`data.enc.json`, והדפדפן מפענח אותו אחרי הזנת הסיסמה.

## קבצים

- `index.html`: האתר.
- `data.enc.json`: המידע המוצפן. זה הקובץ היחיד עם מידע שעולה ל-GitHub.
- `family.json`: המידע הגלוי. נשאר במחשב בלבד.
- `.password`: הסיסמה. נשארת במחשב בלבד.

## עדכון מידע

1. לערוך את `family.json`.
2. להריץ מתוך התיקייה: `swift scripts/encrypt.swift`
3. לעשות commit ו-push ל-`index.html` ול-`data.enc.json`.

## החלפת סיסמה

`swift scripts/encrypt.swift --new-password` יוצר סיסמה חדשה ומצפין מחדש. כל המכשירים יצטרכו להזין אותה שוב. עותקים ישנים נשארים בהיסטוריה של הריפו, ואפשר לפענח אותם עם הסיסמה הישנה.

## גיבוי

`family.json` ו-`.password` לא נמצאים ב-GitHub. אם הם יאבדו, יהיה צריך לשחזר את המידע מהמסמכים. כדאי לשמור עותק במקום מאובטח.
